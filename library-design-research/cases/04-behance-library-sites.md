# 04 · Behance 图书馆/书店网站案例

> Behance 图在 `mir-s3-cdn-cf.behance.net`，需进项目页提取。`~` 标记的 hex 为描述推算值。

## 案例

### The London Library — 官网重塑
- **URL**：https://www.behance.net/gallery/3655767/The-London-Library
- **要点**："现代布局 + 古典内容"的平衡范式——书架/大厅实景大图直接做首屏，UI 退后（细线条、低饱和、半透明）
- **配色**：`~#F5F1E8` 纸白 / `~#1E1B16` 墨 / `~#8A6B45` 木

### Zangak Bookstore 电商 — Marog
- **URL**：https://www.behance.net/gallery/153842691/ECOMMERCE-WEBSITE-FOR-ZANGAK-BOOKSTORE
- **要点**："站在实体书店里呼吸书卷气"的转译方法论；mega menu + 多维筛选模拟"沿书架浏览"；页面标题即品牌文案

### JOSÉ BARBA LIBRERO 古籍店
- **URL**：https://www.behance.net/gallery/100449695/JOSE-BARBA-LIBRERO-VINTAGE-BOOK-STORE
- **要点**：以《Codex Seraphinianus》为灵感的图鉴式插画系统；可借鉴为站点做一套"图鉴式"装饰元素（印章/图表/藏书票）作章节分隔

### DreamBooks 二手书店
- **URL**：https://www.behance.net/gallery/248744351/DreamBooks-Used-Bookstore-Rebrand-Reposition
- **要点**：从旧书批注/页边笔记/印章提取设计语言——纸张纹理+涂鸦+印章营造"真实二手书店触感"；传统衬线 × 几何无衬线混血

### Mark Funke Rare Books 珍本书商
- **URL**：https://www.behance.net/gallery/239054343/Mark-Funke-Rare-Books
- **要点**：blackletter 黑体字 × Tschichold 现代排版的混血；单件藏品多角度实物摄影"值得收藏的目录"——作品详情页参考

## 可借鉴点

1. **实景摄影做主角，UI 退后**——书架大图直接当 hero，控件细线低饱和
2. **材质触感系统**：纸纹/批注/印章/藏书票做 hover 与装饰细节，`mix-blend-mode:multiply` 纸纹叠加成本低质感高
3. **衬线×现代混血**：标题高对比古典衬线（可点缀 blackletter/drop cap），正文功能文字用干净无衬线
4. **配色锚点**：奶油底+墨黑+一个暖强调色（砖橙/旧金/深青）为最高频组合；暗色场景用"熏黑竹"单色让书架图独占色彩
5. **IA 隐喻**：mega menu=沿架浏览；书架层格映射内容分类；滚动触发层间推拉镜头

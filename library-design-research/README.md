# 古典图书馆风格前端设计案例库

为个人展示网站（Astro + Three.js + GSAP + page-flip）收集的「写实古典大书架/图书馆」方向参考案例。

## 目录结构

- `cases/` — 每个调研主题一个 markdown 文件（22 个），内含多个案例：来源 URL、直链图、设计要点、实现手法
- `images/` — 已下载素材与实拍截图：图书馆摄影、纹理 PNG、应用 UI、19 个参考站 Playwright 截图（`site-*.jpg`）
- `CASES.md` — 全部案例索引、图片清单与"先看这 6 个"速查
